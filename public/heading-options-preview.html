3 אפשרויות לכותרות

בחרו A / B / C — ואעדכן את האפליקציה

אופציה A — קו תחתון רך

הוסיפו את הזיכוי הראשון

צלמו שובר או תעודת זיכוי, אשרו את הפרטים — והיתרה תופיע כאן.

כותרת נקייה עם קו גרדיאנט קטן מתחת. נראה רגוע ומודרני, בלי רעש.

אופציה B — תגית קטנה מעל
התחלה

הוסיפו את הזיכוי הראשון

צלמו שובר או תעודת זיכוי, אשרו את הפרטים — והיתרה תופיע כאן.

תגית קטנה מעל הכותרת נותנת היררכיה ברורה. מתאים גם למובייל וגם לדסקטופ.

אופציה C — כרטיס רקע עדין

הוסיפו את הזיכוי הראשון

צלמו שובר או תעודת זיכוי, אשרו את הפרטים — והיתרה תופיע כאן.

הכותרת יושבת על רקע רך ורוד־ירוק. בולטת יותר, מרגישה חמה ומוזמנת.
